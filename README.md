# RALLIQ — Pickleball Court Reservation & Open Play Portal

A full-stack web application built with **PHP 8+**, **Microsoft SQL Server**, and **Bootstrap 5.2.3** for managing pickleball court rentals and public Open Play drop-in sessions.

## User Roles
- **Players:** Discover registered venues, book non-conflicting private court time slots, join or leave Open Play rosters (including guest slots), and track booking history.
- **Facility Managers:** Register venues and courts, upload facility photos, block unavailable court hours, host/cancel Open Play sessions, and manage private court rentals.

## Tech Stack
- **Frontend:** HTML5, CSS3, Bootstrap 5.2.3, Vanilla JavaScript
- **Backend:** PHP 8+ with sql queries & session-based RBAC
- **Database:** Microsoft SQL Server
